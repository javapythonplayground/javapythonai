# Multi-Agent Airline Ticket Booking System

This project demonstrates a simple production-style multi-agent airline booking system using:

- Python FastAPI backend
- React frontend
- PostgreSQL database
- Docker & Docker Compose
- Simple RAG (Retrieval Augmented Generation)
- Root Agent + Sub Agents communication

## Agents

1. Root Agent
2. Availability Agent
3. Pricing Agent
4. Booking Agent
5. RAG Knowledge Agent

## Run

```bash
docker-compose up --build
```

Frontend:
http://localhost:3000

Backend:
http://localhost:8000/docs
```
